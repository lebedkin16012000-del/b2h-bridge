# B2H Bridge — Blender → Houdini

**Blender: 4.8.3 Beta · Houdini Model Import: 0.5.0**

Экспорт моделей и PBR-материалов из Blender в Houdini Solaris / Karma через USD.

## Скачать

- [B2H Bridge 4.8.3 Beta для Blender](downloads/B2H_Bridge-4.8.3-Beta.zip?raw=true)
- [B2H Model Import 0.5.0 для Houdini](downloads/B2H_Model_Import_Houdini_0.5.0.zip?raw=true)

## Что нового по сравнению с опубликованной 4.0.0 Beta

- Экспорт и запекание в отдельном процессе Blender: интерфейс остаётся доступным, есть прогресс и отмена.
- Расширена обработка сложных материалов: вложенные группы, Mix Shader, Add Shader, карты IOR и transmission.
- Повторное использование материалов и одинаковых текстур уменьшает количество дублей.
- Локальный кэш запекания, читаемые имена текстур и переносимые папки экспорта.
- Добавлена настройка запекания 3D-процедурных материалов на всю площадь UV-тайла.
- Отдельная панель Houdini проверяет экспорт, собирает MaterialX и назначает материалы по точным путям USD.
- Повторный импорт обновляет сеть этого ассета; при ошибке замены старые узлы сохраняются.

## Важно: подготовьте модель перед экспортом

**B2H Bridge — прежде всего инструмент автоматического запекания материалов в текстуры и подготовки экспорта. Качество результата зависит от подготовки модели. UV-развёртку нужно проверять самостоятельно.**

- Проверьте UV в **UV Editing**: для обычного запекания острова должны находиться в пределах одного тайла 0–1, иметь отступы и не перекрываться, если на этих участках нужен разный рисунок.
- Несколько материалов могут находиться на одном объекте, но их запекаемые участки не должны конфликтовать на общей UV-развёртке. Надёжнее заранее разделить модель по материалам: **Edit Mode → A → P → By Material**. Затем проверьте UV каждой получившейся части.
- Разные объекты с отдельными текстурами могут использовать одинаковую область 0–1. Проблема — наложение участков, записываемых в одну и ту же текстуру.
- **Split Meshes By Material** помогает с назначением материалов в Houdini, но не заменяет проверку UV и подготовку модели.
- Проверьте назначения материалов на полигонах, доступность исходных текстур, нормали и вид модели в Blender. Сохраните подготовленную копию сцены.
- **Перенос рига пока не рекомендуется. У автора перенос рига не получился; рабочий перенос рига этой версией не подтверждён.** Для первого теста используйте статическую модель без рига. Анимацию и риг готовьте отдельно; при разделении по материалам анимация экспортных копий очищается.

## Пошаговый процесс работы

### 1. Установите аддон Blender

1. Скачайте **B2H_Bridge-4.8.3-Beta.zip** по ссылке выше.
2. Откройте **Edit → Preferences → Add-ons → Install from Disk**, выберите ZIP и включите **B2H Bridge v4.8.3 Beta**.
3. Откройте подготовленную модель и перейдите в **Object Mode**.
4. Выделите mesh-объекты, которые хотите перенести.
5. В 3D Viewport нажмите **N** и откройте вкладку **Houdini**, панель **Houdini Bridge**.

### 2. Настройте экспорт

Названия приведены для английского интерфейса; при русском языке часть подписей переводится.

| Раздел | Куда нажать | Что выбрать |
| --- | --- | --- |
| Export | **Export Folder** | Папка, куда будут сохранены модель и текстуры. Например, `D:/B2H_Exports/TestModel`. |
| Export | **Asset Name** | Понятное имя ассета, например `TestModel`. |
| Export | **Selected Only** | Оставьте включённым для экспорта выделенных mesh-объектов. |
| Bake | **Bake Complex Materials** | Оставьте включённым для автоматического запекания сложных и процедурных материалов. |
| Bake | **Fast Bake** | Оставьте включённым: запекание выполняется только там, где требуется. |
| Bake | **Bake Resolution** | Для первого теста используйте 1024; при необходимости увеличьте до 2048 или 4096. |
| Materials | **Split Meshes By Material** | Оставьте включённым, особенно если у объекта несколько материалов. |

Остальные настройки для первого теста оставьте по умолчанию. Автоматические UV-настройки не гарантируют подходящую развёртку — исходные UV всё равно проверяйте самостоятельно.

### 3. Выполните экспорт

1. Нажмите большую кнопку **Export Stable PBR Bridge** внизу панели.
2. Дождитесь завершения: панель показывает этап, прогресс и время.
3. В папке экспорта должны появиться **.usd / .usdc**, **textures/** и **<asset>_bridge.json**. Не переносите USD отдельно от текстур и JSON.
4. Если экспорт завершился с ошибкой, проверьте **<asset>_bake_report.txt** и **<asset>_export_report.txt**, если они созданы.

### 4. Установите импортер Houdini

1. Скачайте **B2H_Model_Import_Houdini_0.5.0.zip** и полностью распакуйте его.
2. Закройте Houdini и запустите **install_windows.bat**.
3. После успешной установки запустите Houdini.
4. Откройте панель **B2H Model Import v0.5.0** через **Windows → New Pane Tab Type**. Если пункт находится в подменю Python Panel, выберите его там.

### 5. Импортируйте модель

1. Нажмите **Select Export Folder**.
2. Выберите папку, указанную в Blender в **Export Folder** — ту, где лежит **<asset>_bridge.json**.
3. Нажмите **Refresh** и дождитесь появления ассета в таблице.
4. Выберите его строку и нажмите **Import / Update Selected**.
5. После импорта проверьте модель и материалы в **Solaris /stage**, затем сделайте пробный рендер в Karma.
6. Если появились предупреждения, прочитайте статус импорта: например, часть текстур может отсутствовать.

Для обновления модели экспортируйте её с тем же именем в ту же папку, затем в Houdini нажмите **Refresh → Import / Update Selected**. Не удаляйте файл **<asset>_bridge.json** между экспортами: он хранит идентификатор ассета для обновления.

**Альтернативный импорт:** откройте **COPY_THIS_TO_HOUDINI.txt** в папке экспорта, скопируйте команду в **Windows → Python Shell** Houdini и выполните её.

Подробная инструкция по установке импортера: [Houdini — README_RU](houdini/README_RU.md).

## Версии и ограничения

- В коде аддона указан минимум Blender 5.0; импорт ориентирован на Houdini 21.0.559.
- Это beta. Проверены целостность архивов, синтаксис Python, JSON/XML и контрольные суммы импортера. Полный экспорт и рендер в Blender/Houdini при этой публикации не запускались.
- UDIM пока представлен только метаданными, без полноценного запекания тайлов.
- Разделение по материалам очищает анимацию объектов на экспортных копиях; анимированные модели требуют отдельной проверки.
- Известная особенность импортера: при подключённой карте displacement значение масштаба 0 заменяется на 0.01.
- Исходные ZIP опубликованы без изменения кода.

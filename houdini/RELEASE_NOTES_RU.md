# B2H Model Import 0.5.0

Первый публичный пакет обновлённого импортёра Houdini.

Главные изменения:

- переносимая установка без путей конкретного пользователя;
- один импортёр для панели Houdini и скриптов, создаваемых B2H Bridge;
- точные назначения материалов вместо широкого поиска по части имени;
- безопасное обновление уже импортированных ассетов;
- полный поддерживаемый набор PBR-карт в Karma MaterialX;
- проверка манифеста и честный отчёт о результате;
- фоновое сканирование и полоса выполнения;
- очищенный публичный пакет без старых модулей и `__pycache__`.
- автоматическая установка панели сразу для всех найденных версий Houdini.

Перед установкой закройте Houdini. После установки откройте панель
**B2H Model Import v0.5.0**.

# B2H Model Import 0.5.1

Исправлен прямой импорт B2H в Houdini.

Главное изменение:

- Перед выходом геометрии создаётся `RESTORE_PRIMARY_UV`.
- Если у геометрии есть основная Houdini UV-развёртка (`uv`), удаляется конфликтующий остаточный `st`, чтобы SOP Create экспортировал корректный `primvars:st`.
- Если основной `uv` нет, существующий `st` сохраняется.
- Дополнительные UV-наборы не удаляются.
- Версия импортёра, панели и UI обновлена до 0.5.1.

Blender-аддон менять не требуется.

Для новых импортов исправление применяется автоматически. Для уже импортированного ассета используйте **Import / Update Selected**, чтобы пересоздать генерируемую ветку импортёра.

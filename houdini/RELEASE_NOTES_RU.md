# B2H Model Import 0.5.0

First public package of the updated Houdini importer.

Main changes:

- Portable installation without user-specific paths.
- One shared importer for the Houdini panel and scripts generated by B2H Bridge.
- Exact material assignments instead of broad substring matching.
- Safe updates of previously imported assets.
- Support for the documented set of PBR maps in Karma MaterialX.
- Manifest validation and clear result diagnostics.
- Background scanning and a progress bar.
- Clean public package without obsolete modules or `__pycache__`.
- Automatic panel installation for all detected Houdini versions.

Close Houdini before installing. After installation, open **B2H Model Import v0.5.0**.
